# Third-party assets

## Earth texture

Source: NASA Blue Marble, land surface / ocean / ice map.

Original image: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.png

The downloaded 2048 × 1024 image is resized to 1024 × 512 for this mobile project. Credit: NASA / Earth Observatory.

NASA media guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/

## City-light night texture

Source: [NASA Black Marble 2016 grayscale global map](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/).

Original 3600 x 1800 JPEG: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144897/BlackMarble_2016_01deg_gray.jpg

Credit: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Roman, NASA GSFC. The original file is included as `assets/earth_night.jpg`; Godot imports it at a maximum width of 1024 pixels with filtering and mipmaps. The Earth shader extracts urban radiance and applies an artistic golden emission color.
